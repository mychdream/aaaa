# 空白模板填写说明

双击 dist/index.html 预览。使用文本编辑器打开这个文件，搜索“填写”，把相应 HTML 注释替换为实际内容即可。姓名、职称、基本信息、简介、项目、招生、新闻、经历、论文均留空。

照片：将照片保存为 dist/assets/photo.jpg，在 id="t_pic" 的 div 中添加 <img src="assets/photo.jpg" alt="教师照片">。

正文：每段使用 <p>文字</p>。教育和工作经历可复制对应的 <li>...</li> 增加记录。

学校标识及校园背景沿用原页面，分别是 assets/logo.png 和 assets/bannerbg.jpg；用于其他学校时请自行替换，并修改顶栏的学校名称。

顶部登录、学校、English 仅保留文字排版，未连接后台。需要链接时改成 <a href="实际网址">文字</a>。访问次数未连接统计服务。

模板保留原页 1300px 固定宽度，手机也按原版桌面布局显示。空栏目高度由 style.css 末尾的 .blank-* 控制，填写后可调整。

在浏览器里不能直接编辑保存；修改 HTML 后保存并刷新即可。所有素材均已本地化，无须联网也能预览。
